# Mein Authoria – Übersicht der Dateien

Diese Dateien bilden zusammen die Grundlage für den Master-Prompt (Tag 4 · Gestaltung).

| Datei | Inhalt | Rolle im Master-Prompt |
|---|---|---|
| `aufgabe.md` | Aufgabenblatt der Dozentin | **Rahmen:** Was verlangt ist |
| `recherche.md` | Tag 1: Recherche, Insights, Persona, HMW, Problem Statement | **Kontext:** Warum und für wen |
| `regeln.md` | No-gos, Gestaltungsprinzipien, ethisches Prinzip | **Regeln:** Was immer gilt (Vorrang vor allem anderen) |
| `struktur.md` | Tag 2: Szenarien, Sitemap, Steckbriefe, User Flow, Skizzen-Entscheidung | **Struktur:** Welche Seiten, was passiert dort, wie hängen sie zusammen |
| `interaktion.md` | Tag 3: Intent, Scaffolding, Input, Output, Refinement, Zustände | **Spezifikation:** Wie der Kern-Moment im Detail funktioniert |

## Reihenfolge beim Lesen
1. `aufgabe.md` → 2. `recherche.md` → 3. `regeln.md` → 4. `struktur.md` → 5. `interaktion.md`

## Umfang des Prototyps
- **Vollständig:** Szenario S1 „Sackgasse“ → Schreibraum, Innehalten-Panel, Spuren legen, Versionen & Zweige
- **Als Zustand:** Grenzfall S3 („Ich schreibe keine Prosa …“) im Innehalten-Panel
- **Optional:** Szenario S2 „Wo war ich?“
